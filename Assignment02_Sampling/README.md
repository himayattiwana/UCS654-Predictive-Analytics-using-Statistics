# Assignment 02 - Sampling

This repository contains my solution for the Sampling assignment in UCS654 (Predictive Analytics using Statistics).

## Files

- `Creditcard_data.csv` - dataset used in the assignment
- `Sampling_Assignment.ipynb` - complete notebook with all steps and results

## Work done

1. Loaded the given imbalanced credit card dataset.
2. Converted it into a balanced dataset.
3. Created five different samples.
4. Applied five sampling techniques (Sampling1 to Sampling5).
5. Trained five machine learning models (M1 to M5).
6. Compared model accuracy across all sampling techniques.
7. Identified which sampling method gives higher accuracy for each model.
